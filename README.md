# GTM AI Directory

A register of GTM AI agents. The directory lists each agent, and every agent has its own page covering what it does, how it works, what it connects to, who owns it, and where it sits in the Propose, Stage, Try, Deploy process.

**Live preview: https://jomarebalida-cloud.github.io/gtm-ai-directory/**

## Agents

| Agent | Stage | What it does | Page |
|---|---|---|---|
| Data to Value Business Case Agent | 1 · Propose | Builds a board-ready business case for any Alteryx One use case from a single prompt. | [Open](https://jomarebalida-cloud.github.io/gtm-ai-directory/data-to-value-business-case-agent.html) |
| Account End of Year Planning Agent | 2 · Stage | Plans the end of the year in Claude with account and segmentation data. | [Open](https://jomarebalida-cloud.github.io/gtm-ai-directory/account-end-of-year-planning-agent.html) |
| Personalyze AI Outreach Agent | 4 · Deploy | Drafts personalized emails and LinkedIn messages inside Outreach tasks. | [Open](https://jomarebalida-cloud.github.io/gtm-ai-directory/personalyze-ai-outreach-agent.html) |

## Files

- `index.html`: the directory home page
- `data-to-value-business-case-agent.html`
- `account-end-of-year-planning-agent.html`
- `personalyze-ai-outreach-agent.html`

Each page is a single static HTML file. The site is served with GitHub Pages from the `main` branch.
