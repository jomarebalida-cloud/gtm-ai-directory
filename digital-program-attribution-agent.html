ABOUT THIS AGENT

What it does

CX runs digital programs — in-product guides, lifecycle email, community, education, adoption and renewal campaigns — and is asked what they returned. The answer lives in two places: engagement data on one side, the FP&A revenue base on the other. This agent joins them through the digital program attribution model and reports a program in the retention terms the business already uses, NRR and GRR.

It runs as an MCP over DataHub and Snowflake and is used in Gemini. It reads the FP&A metrics as published rather than recomputing them, so a program review and a finance review start from the same number.

How it works

1A program owner asks, in plain language, how a program performed — overall, by segment, or for one cohort.
2Gemini calls the MCP.
3The MCP reads program engagement, account, and FP&A retention data from Snowflake, and the definitions behind them from DataHub.
4It applies the attribution model: which accounts the program touched, inside which window, against a matched set it did not touch.
5Gemini returns the NRR and GRR read with the window, the comparison set, and the caveats stated. The program owner reviews it before it is used.

SEMANTIC LAYER

The definitions behind the agent

The attribution model is only as good as the words under it: what counts as a touch, how long credit lasts, and whose retention number is the retention number. Defined once, these keep CX reviews, FP&A reporting, and other agents on the same figures.

Net revenue retentionThe FP&A definition, read as published. The agent reports it and never recalculates it, so a CX read and a finance read cannot drift apart.
Gross revenue retentionAlso FP&A's, and read the same way. GRR isolates churn and downgrade, which is what most CX programs are actually aimed at.
Account hierarchy joinThe FY26 hierarchies, so a program touch at a subsidiary and the revenue at its parent roll up to the same account. Shared with the Account End of Year Planning Agent.
Program touchWhat makes an account touched by a program, per channel: the action that counts, who has to take it, and the minimum engagement below which it is noise.
Attribution windowHow long after a touch a retention outcome is still credited to the program, and how credit is split when several programs touch the same account before one renewal.
Comparison setThe untouched accounts a program is read against, matched on segment, size, vertical, and renewal timing. Without it the model reports a correlation and calls it a result.
